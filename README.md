# Celestial-Bodies-Database
In this project a database of celestial bodies was built using PostgreSQL.

A PostgreSQL database project built as part of the [freeCodeCamp](https://www.freecodecamp.org/) Relational Database curriculum.

The project models celestial objects and their relationships, including galaxies, stars, planets, moons, and asteroids.

## Practiced

- Creating and modifying tables using SQL.
- Defining primary keys and foreign key relationships.
- Applying constraints such as `NOT NULL` and `UNIQUE`.
- Working with integer, numeric, boolean, and text data types.
- Inserting data and managing automatic ID generation using sequences.

## Technologies

- PostgreSQL
- SQL

This project was created for practicing relational database design and SQL fundamentals.

## `universe.sql`

This file contains the PostgreSQL database generated after completing all the required tasks in the freeCodeCamp *Build a Celestial Bodies Database* project.

It includes the database structure, tables, relationships, constraints, and inserted data created throughout the project. It serves as a complete SQL representation of the finished database, allowing it to be recreated in a PostgreSQL environment.
